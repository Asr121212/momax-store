# متجر موماكس - Momax Store

موقع ويب ثلاثي الأبعاد احترافي لمتجر إلكترونيات موماكس (Momax).

## الميزات 🎯

✅ **عرض المنتجات**: معرض جميل وتفاعلي لجميع المنتجات الإلكترونية

✅ **سلة التسوق**: إمكانية إضافة عدة منتجات والاحتفاظ بها قبل الشراء

✅ **تكامل واتساب**: ربط سهل مع واتساب الأعمال لإتمام الطلب

✅ **رسالة مفصلة**: تتضمن جميع المنتجات والكميات والأسعار

✅ **تصميم عربي**: دعم كامل للغة العربية وخط Cairo الفاخر

✅ **تخزين محلي**: حفظ السلة في المتصفح للعودة إليها لاحقاً

## المنتجات المتوفرة 📦

- شواحن سريعة بمختلف الأنواع
- كابلات بيانات عالية الجودة
- بطاريات خارجية
- حوامل الهواتف
- واقيات الشاشة
- وملحقات إلكترونية أخرى

**جميع الأسعار: 2000 ريال**

## التقنيات المستخدمة 🛠️

- HTML5
- CSS3 (مع دعم Grid و Flexbox)
- JavaScript (Vanilla JS)
- FontAwesome للأيقونات
- Cairo Font للخطوط العربية

## كيفية الاستخدام 👥

1. فتح الموقع
2. تصفح جميع المنتجات
3. اختيار المنتج والضغط على "شراء" أو "عرض التفاصيل"
4. إضافة الكمية المطلوبة
5. إضافة منتجات أخرى من السلة
6. الضغط على "إتمام الطلب عبر واتساب"
7. سيتم فتح واتساب برسالة مفصلة عن الطلب
